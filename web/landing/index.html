三端说明

同一套数据，三种使用方式

员工端三端能力对齐；管理后台只在网页版提供。安装方式与通知能力存在差异，下面按实际情况说明。

网页版

员工端 + 管理后台
浏览器即用 · 无需安装
  • 员工端：任务、排班、效期、消息、考勤、报销等全部页面
  • 管理后台：仅网页版提供，店员端 App 不包含管理功能
  • 消息：站内未读角标与消息列表
  • 提醒：不弹系统通知；效期扫码需 HTTPS 且浏览器支持摄像头

安卓 App

原生 Kotlin · Jetpack Compose
APK 直接安装 · 本地通知
  • 形态：原生应用，直接调用 PHP 接口，不内嵌网页
  • 安装：安装 APK 即可，需允许“安装未知来源应用”
  • 通知：本地通知；前台每 5 分钟拉取，后台 WorkManager 约 30 分钟兜底
  • 限制：仅员工端；FCM 远程推送为预留能力，需自行配置服务端

iOS App

原生 SwiftUI · iOS 15+
未签名 IPA · 需自签安装
  • 形态：原生应用，直接调用 PHP 接口，不加载网页
  • 安装：Sideloadly / AltStore 用 Apple ID 自签；免费账号 7 天有效、最多 3 个 App，到期需重新签名
  • 通知：本地通知；前台 5 分钟轮询，后台刷新约 30 分钟（系统调度不保证准时）
  • 推送：APNs 默认关闭；系统级远程推送需 Apple Developer Program（付费）并配置 Push Notifications

部署与接入

上传到虚拟主机，跟着向导完成安装

系统为 PHP + MySQL 架构，不依赖 Composer 或额外服务，可直接放在虚拟主机的子目录中运行。

1

上传程序到子目录

将网页端文件上传到虚拟主机的目标目录，例如 /staff/，保持目录结构不变。

2

访问安装向导

浏览器打开 https://你的域名/staff/install.php，向导会先检查 PHP 版本、PDO 与 PDO MySQL 扩展。

3

填写数据库信息

输入主机提供的 MySQL 地址、库名、账号与密码；向导自动建库、执行建表脚本并写入初始配置。

4

创建店长账号并登录

设置管理员手机号与密码，完成后即可登录网页版；员工账号由管理后台创建并分配门店与岗位。

5

打包 App 指向你的域名

在安卓 / iOS 工程的配置文件里把站点地址改成你的域名，重新打包 APK / IPA；App 只调用接口，不内置网页资源。

环境要求

  • PHP7.4 及以上
  • 数据库MySQL 5.7+ / 8.0
  • 必需扩展PDO、PDO MySQL
  • 可选扩展Fileinfo
  • 依赖管理无需 Composer
  • 协议建议启用 HTTPS
'db' => [
  'host' => 'localhost',
  'port' => 3306,
  'name' => 'store_staff',
  'user' => '数据库账号',
  'pass' => '数据库密码',
  'charset' => 'utf8mb4',
];

安装向导会自动生成配置；如手动迁移，可参考 config.sample.php。Fileinfo 缺失时上传校验会自动降级为文件头检测。

常见问题

上线前需要知道的几件事

三端的数据是同一套吗？

是。网页版、安卓 App、iOS App 都直接调用同一套 PHP 接口，任务、排班、效期、考勤等数据实时一致；员工在任一端的操作，其他端刷新后即可看到。

iOS 为什么需要 7 天重新签名？

当前 iOS 包以未签名 IPA 交付，使用免费 Apple ID 通过 Sideloadly 或 AltStore 自签安装。免费账号的签名有效期为 7 天、最多同时安装 3 个 App，到期后需要重新签名；AltStore 可在同一 Wi-Fi 下自动续签。若需长期有效或上架，需要 Apple Developer Program 付费账号。

为什么 iOS 收不到后台推送？

系统级远程推送（APNs）需要付费开发者账号与 Push Notifications 权限，当前默认关闭。已内置的是本地通知：前台每 5 分钟拉取一次，后台由系统刷新任务约 30 分钟兜底，调度时间由 iOS 决定，不保证准点。

管理后台可以在 App 里用吗？

不可以。管理后台只在网页版提供；安卓与 iOS App 是员工端，用于日常任务、排班、效期、考勤、报销、通讯录与日程。

可以装在子目录吗？

可以。把网页端文件放到任意子目录后访问其中的 install.php 完成安装即可；页面与接口均使用相对路径，无需绑定域名根目录。
